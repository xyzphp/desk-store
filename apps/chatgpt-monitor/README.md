# GPT 监控

ChatGPT 多账号用量监控应用，通过受控代理连接自托管的 [codexMeter](https://github.com/xyzphp/codexMeter) 监控服务，在桌面卡片和独立窗口中查看并管理多个账号的额度使用情况。

## 功能

- **桌面卡片**：显示 5 小时与本周剩余额度百分比及重置时间，支持直接在卡片上切换查看不同账号。
- **窗口管理**：通过 `xyzos:proxy` 桥读取、切换与管理监控服务中的账号和设置，内置接口文档与在线调试页。
- **凭据隔离**：Basic Auth 账号密码由网关加密保存并在转发时注入，前端页面无法获取上游凭据。

## 安装时需要配置

- **ChatGPT 监控服务地址**：默认为占位地址 `https://chatgpt-monitor.example.com`，安装确认时填写你的监控服务地址。
- **上游账号与密码**：监控服务的 Basic Auth 凭据，仅存储在网关侧。
