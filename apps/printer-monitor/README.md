# 3d打印监控

通过受控只读代理连接自托管的 3D 打印监控服务，在应用窗口和桌面卡片中实时查看打印机状态、进度、喷嘴 / 热床温度以及打印中摄像头画面。

## 功能

- **实时状态监控**：显示当前任务名称、打印状态、完成百分比、剩余时间、打印层数以及喷嘴和热床温度。
- **摄像头画面**：通过受控代理拉取 `/api/camera/frame` 实时画面，只允许 `GET` 读取。
- **桌面卡片**：支持作为桌面状态卡片展示并跟随系统浅色 / 深色主题切换。

## 安装时需要配置

- **打印监控 Go 服务地址**：默认为占位地址 `http://printer-monitor.example.com:8090`，安装确认时改成你的监控服务地址；该代理仅开放 `/api/printer`、`/api/camera/frame`、`/healthz` 三个只读路径。
