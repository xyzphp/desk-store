# 文章

开源的文章管理与公开阅读应用（格式 2，Go Wasm 后端 + React 界面）。

## 主要功能

- **写作工作台**：三栏可调宽度布局（侧栏、文章库、编辑区）、图文卡片与紧凑列表切换、专注模式与刷新状态恢复。
- **Markdown 编辑器**：单栏 / 双栏 / 可编辑预览、60 步撤销重做、图片尺寸与多列排列、封面横幅（900×383）与方形（500×500）裁剪。
- **分类与标签**：最多三级树状分类、行内新建 / 重命名 / 删除确认、拖拽调整层级、级联筛选与使用中删除保护。
- **文件引用保护**：上传、粘贴与选择本人管理文件，通过平台 `files.reference` 与 `files.save` 保存并保护被文章和站点引用的文件。
- **站点设置与每日一言**：品牌、页面横幅（五页独立开关与背景）、页脚（纯色 / 图片背景、最多 8 分栏与自定义行）、分类 / 标签管理、每日一言定时拉取与历史记录。
- **公开阅读站**：经典博客主题、首页 / 详情 / 归档 / 分类 / 标签 / 搜索 / 分页（URL 保存）、球面标签云、头像眼睛跟随与弹幕、火箭返回顶部、深浅主题与附件下载；支持 RSS 与 Sitemap。
- **AI 辅助与集成**：悬浮选区优化、表单智能补全、封面与正文插图生图（支持在应用设置中自定义提示词）、个人令牌接口权限点、MCP 工具 / 资源 / 提示模板、写作技能与内置配置导入。

## 权限说明

- 默认不向普通账号授予访问权限，管理员可在账号与角色管理中按需授权。
- 应用内权限 `site.settings`（站点设置）由管理员自动拥有，也可授权给其他账号或角色。
- 公开入口默认关闭，由管理员在「应用管理 → 公开入口」开启并绑定路径别名（建议 `/articles`）。
