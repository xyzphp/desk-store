# 接口标准（草案）

本目录是应用包、后端模块与商店数据格式的**下一版标准草案**，供商店与目标系统两侧同时实现。草案不出现在商店网站的文档目录中；某一部分在商店与目标系统都实现并发布后，再把对应内容并入 `docs/develop/` 与 `docs/self-host/`，并从这里删除。

| 文档 | 内容 | 状态 |
| --- | --- | --- |
| [01 应用包格式 2](01-package-v2.md) | 组件模型（界面、后端、MCP、技能）、清单新增字段、包目录与上限、能力标记、与格式 1 的兼容 | 草案 |
| [02 后端模块、存储与数据库迁移](02-backend.md) | 后端运行方式、接口约定、宿主能力、三类存储、迁移文件规则与更新流程 | 草案 |
| [03 商店数据格式补充](03-catalog.md) | 索引与详情新增字段、权限摘要扩展、迁移摘要、安全通告、兼容性、校验与 CI 要求 | 草案 |

约定：

- 本目录只描述商店与目标系统之间的**合同**：字段、格式、校验与行为。目标系统内部如何实现不在这里。
- 改动标准时，同一个 Pull Request 里更新本目录与受影响的实现说明；已发布为正式格式的字段只增不改。
- 字段命名：清单（`manifest.json`）使用 `snake_case`，商店数据（`api/v1/*.json`）使用 `camelCase`，与现有格式一致。
