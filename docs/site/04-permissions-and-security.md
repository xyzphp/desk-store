# 权限与安全

Desk Store 与目标系统通过「签名分发 + 清单白名单 + 运行期隔离 + 操作审计」四层防线控制扩展风险。应用清单中的每项声明既是展示给管理员的权限说明，也是服务端的硬性拦截规则。

> **信任底线**：前端沙箱与后端 Wasm 均无法越过清单声明的边界，目标系统在每次请求与能力调用时独立执行鉴权。

## 1. 分发验证链

1. **源码审查**：应用以源码进入 Git 仓库，所有变更在 PR 中明文比对。
2. **确定性打包**：CI 按固定顺序与时间戳生成 ZIP，任何人可用 `appcheck pack` 本地复现 SHA-256。
3. **公钥固定与 Ed25519 签名**：商店离线保护私钥并对版本记录签名；客户端添加商店源时人工核对并固定公钥。
4. **安装前二次校验**：即便签名有效，目标系统安装前仍重新校验清单、文件类型、Wasm 导入表和 SQL 迁移白名单。

## 2. 四重运行隔离

| 隔离层 | 实现方式 | 安全边界 |
| --- | --- | --- |
| **前端沙箱** | `sandbox="allow-scripts"` 不透明源 iframe | 拿不到会话 Cookie，无法访问宿主 DOM、`localStorage` 或其他应用 |
| **后端沙箱** | WASI preview 1 reactor 模块，按请求实例化销毁 | 无宿主机文件、无原始 Socket、无环境变量，仅可调用白名单 `host.*` 函数 |
| **存储隔离** | 独立 SQLite 文件与 `/data` 目录，按 `shared` / `public` / `account` 划分 | 与系统主库物理隔离；`account` 范围由宿主按调用者自动切换 |
| **凭据托管** | 代理认证凭据与 `backend.config` 加密项仅存服务端 | 仅在服务端转发或受控读取时使用，绝不向前端或普通接口回显 |

## 3. 解读权限摘要

安装或更新前，重点核对详情页「权限与安全」与「接口与集成」中的以下信息：

### 访问入口与授权

- **页面来源**：区分包内静态页面（`entry`）、代理上游页面（`gateway_page`）或无界面组件（`none`）。
- **扩展入口**：确认是否启用独立标签页（`standalone`）、桌面卡片（`desktop_widget`）以及公开页面（`public`）。公开入口安装后默认关闭，且 `session: "optional"` 表示访客已登录时会向后端传递脱敏身份。
- **应用内权限与默认授予**：检查 `access.permissions` 定义的子权限颗粒度与 `default_grant` 建议值（管理员可在安装确认页改为不自动授予）。
- **系统接口（`gateway_api`）**：应用以当前用户身份调用的白名单前缀。宿主永久禁止访问会话、账号、角色、令牌、安全与凭据类端点，且严格受调用者自身权限约束。

### 数据存储与网络外联

| 摘要项 | 审查要点 |
| --- | --- |
| **隔离存储** | 确认启用了哪些存储范围（`shared` / `public` / `account`）及声明配额 |
| **受控代理（`proxies`）** | 核对上游地址、可编辑开关、开放的 HTTP 方法与路径前缀及凭据类型 |
| **后端外联（`backend.http`）** | 核对允许直连的域名与方法；生产环境下宿主重解析 DNS 并拒绝回环、链路本地、多播与保留地址 |
| **后台触发（`schedules` / `hooks`）** | 定时任务以无调用者的应用身份运行；公开回调无会话，要求模块使用密钥验签 |

## 4. 路由审计日志与个人令牌

- **路由级操作日志**：后端路由默认对已认证写方法（`POST / PUT / PATCH / DELETE`）自动记录操作人、来源、路由模板、固定操作名、状态码与耗时，不记录正文、查询串或动态 ID；路由亦可声明 `mode: "all"`（禁止用于 `public`）或 `mode: "off"`。
- **个人机器令牌**：仅声明了 `token_scope` 的非公开路由接受个人令牌调用；调用时同时校验令牌勾选范围与账号当前实时权限，且令牌入口禁用 `api_call`。

## 5. AI 与技能安全边界

- **模型脱敏托管**：平台 AI 能力由目标系统代理调用，应用拿不到供应商地址与 API Key，且受账号模型授权与应用每日限额双重约束。
- **MCP 副作用确认**：标注 `destructive: true` 的工具在 AI 助手中每次调用前均需用户确认；远程 MCP（`mcp.remote`）在安装时锁定工具列表。
- **技能零脚本**：`skills/` 仅允许 `.md` / `.txt` / `.json`，禁止任何可执行脚本。

## 6. 安全通告

商店可发布带 Ed25519 签名的 `advisories.json` 与 `advisories.json.sig`，标明受影响 SemVer 范围、严重级别与建议动作（`update` 或 `disable`），客户端检查更新时验签展示提醒。
