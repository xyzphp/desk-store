# 在系统中安装应用

以下以 XYZOS 为例。其他兼容本商店数据格式的系统流程类似。

## 1. 添加商店源

只有管理员可以管理商店源。

1. 打开「应用管理」，切换到「应用商店」栏，点击「商店源」。
2. 填写商店地址，例如本站地址（以 `/` 结尾）。
3. 系统会读取商店的 `api/v1/store.json` 并显示签名公钥的指纹。**与商店公布的指纹核对一致后**再确认添加。
4. 需要访问令牌的商店（例如团队私有商店），按提示填写令牌。令牌加密保存，只会发送给这个商店。

可以添加多个商店源，并调整它们的显示顺序；停用的商店源不再出现在浏览和更新中。

## 2. 浏览与安装

1. 在「应用商店」栏中搜索或按分类浏览，点击卡片查看详情。
2. 详情里列出应用的介绍、版本和权限摘要。确认无误后点击「安装」。
3. 系统从商店下载安装包，校验签名与哈希，再按与手动上传相同的规则完整校验安装包。
4. 进入安装确认：查看权限点与代理，按提示填写服务地址和凭据，然后确认安装。
5. 安装者自动获得使用授权；其他账号需要在账号或角色管理中单独授权。

## 3. 更新

来自商店的应用会记录它的来源商店。商店里有新版本时，「管理应用」列表会显示「更新」。更新同样回到安装确认，新版本扩大了权限时会重点提示。

更新只从应用的来源商店拉取，不会被另一个商店里同名的应用替换。

## 常见问题

**签名校验失败？** 说明安装包或版本记录与商店签名不一致，系统会拒绝安装。请联系商店维护者，不要绕过校验。

**提示应用标识冲突？** 本机已经有同名的应用（手动上传的，或来自其他商店），需要先卸载它。

**应用已下架？** 已安装的应用可以继续使用，但不会再收到更新，建议评估后卸载。
