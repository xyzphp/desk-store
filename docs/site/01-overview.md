# 关于 Desk Store

Desk Store 是面向浏览器桌面系统（例如 XYZOS）的开源应用商店。它有三个特点：

- **应用以源码管理。** 每个应用都是本仓库 `apps/` 下的一个目录。新增或更新应用都通过 Pull Request 完成，评审看的就是源码和版本之间的差异，不接受上传的安装包。
- **发布由 CI 完成。** 合并后，CI 从源码确定性地打出安装包、计算 SHA-256，并用商店的签名密钥签名。同一个提交在任何机器上打出的包都完全一样。
- **商店是静态站点。** 网站、应用索引和应用详情都是静态文件，安装包作为 GitHub Release 资产保存。没有账号体系，也没有数据库。

## 谁会用到这个商店

| 角色 | 做什么 |
| --- | --- |
| 系统管理员 | 在系统中添加商店源，浏览、安装和更新应用，见[在系统中安装应用](02-install-in-xyzos.md) |
| 应用开发者 | 按[应用开发文档](../develop/01-quick-start.md)编写应用，提交 Pull Request 上架，见[提交与评审](03-submit.md) |
| 想自建商店的团队 | Fork 本仓库并配置自己的签名密钥，见[自建商店](../self-host/01-fork.md) |

## 商店里的应用是什么样的

应用是一个静态安装包：清单 `manifest.json`、图标，以及包内的 HTML / CSS / JS 页面（或者由系统代理加载的上游页面）。应用运行在系统提供的沙箱中，拿不到登录会话，也不能直接发起同源请求；需要数据时只能通过清单里声明过的受控代理，由系统在服务端转发。

所以安装一个应用时，真正需要关注的是它的**权限摘要**：它会访问哪些外部服务、是否会以当前用户身份调用系统接口。每个应用的详情页都会列出这些信息。

## 收费

商店里的应用都是开源的，安装包本身不收费。有些应用需要连接作者提供的外部服务，这类应用会标注「需订阅服务」或「基础免费」，并附上服务说明链接；费用在作者的服务一侧结算，与商店无关。
