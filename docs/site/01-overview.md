# 关于商店

Desk Store 是面向浏览器桌面系统的开源应用分发与能力规范仓库。所有应用以源码形式提交，通过自动化校验、确定性打包与数字签名对外分发。

> **设计原则**：源码透明可审、构建字节可复现、权限声明即服务端白名单、静态站零运维可自建。

## 核心机制

- **源码即应用**：每个应用对应仓库 `apps/<slug>/` 目录，通过 Pull Request 提交和升级；评审聚焦源码、清单声明与权限变化，不接受预编译安装包。
- **确定性打包与签名**：合并后由 CI 在固定工具链环境下确定性打包、计算 SHA-256 并使用 Ed25519 私钥签名；同一提交在任意环境打出的包完全一致。
- **统一组件与平台能力**：支持格式 1（纯静态 / 受控代理）与格式 2（前端界面、WebAssembly 后端、隔离存储、平台能力 v1、MCP 工具与技能、多端入口）。
- **纯静态与可自建**：网站、目录索引、详情元数据与安全通告均为静态文件，团队可 Fork 仓库并配置自有密钥快速搭建公开或私有商店。

## 应用组件形态

商店根据 `manifest.json` 声明的组件组合自动归类，各应用自身的具体功能与使用说明由对应应用详情页的 `README.md` 提供：

| 类型标签 | 组成方式 | 界面呈现 |
| --- | --- | --- |
| **应用** | 包含窗口界面（`ui`），可选配桌面卡片或后端模块（`backend`） | 出现在桌面、程序坞与窗口工作区 |
| **混合** | 界面与 AI 工具（`mcp`）或技能（`skills`）组合 | 同时提供窗口交互与 AI 集成能力 |
| **MCP** | 仅声明工具、资源或提示模板（无 `ui`） | 不出现在桌面与程序坞，供 AI 助手调用 |
| **技能** | 仅包含纯文本 `SKILL.md` 与参考资料（无 `ui`） | 不出现在桌面与程序坞，供 AI 助手加载 |

## 开源与许可

商店收录的应用源码均须采用受支持的开源 SPDX 许可证，安装包本身免费。依赖外部托管服务的应用会在 `store.json` 中标注 `freemium` 或 `subscription` 并附服务说明链接，相关费用与商店无关。
